# 有趣的网页设计

这里收集一些用 HTML 和 CSS 做的网页小实验。目前收录的是 **立方体相册**。

## 立方体相册

![立方体相册旋转及悬停展开效果](立方体相册/preview.gif)

一个由六张图片组成的双层 3D 立方体。它会持续旋转；鼠标移到相册上时，外层的六个面会向外展开。

- [查看项目文件](立方体相册/)
- 在本地打开 [`立方体相册/index.html`](立方体相册/index.html)，即可体验完整的悬停交互。无需安装依赖。
- 在GitHub Pages打开[立方体相册](https://cmwlvip.github.io/html/立方体相册/)
